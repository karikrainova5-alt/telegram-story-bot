# Instagram Auto-Poster Bot

Telegram-бот, который публикует посты (фото, видео/Reels, карусели) в Instagram
сразу или по расписанию — через **официальный Instagram Graph API**.
Это легальный инструмент автоматизации контента, аналог Later/Buffer/Hootsuite.

Никакой накрутки лайков/просмотров/подписчиков здесь нет и не может быть —
такие сервисы нарушают условия Meta и обычно строятся на фейковых аккаунтах;
это прямой путь к бану клиента, поэтому в продукт такое закладывать не стоит.
Зато автопостинг и official-статистика — то, что реально можно продавать
SMM-агентствам и блогерам на постоянной основе (подписка).

## Что умеет

- Публикация фото, видео (в т.ч. Reels) и каруселей
- Публикация "сейчас" или по расписанию (дата/время)
- Список запланированных постов, отмена
- Мультипользовательский — каждый подключает свой Instagram-аккаунт
- Реальная официальная статистика поста (лайки, охваты, показы) без накрутки

## Ограничение платформы (важно объяснить клиентам)

Instagram Graph API работает **только** с аккаунтами:
1. Instagram **Business** или **Creator** (не личный)
2. Подключёнными к странице **Facebook**

Личные аккаунты через официальный API постить нельзя — это ограничение
самой Meta, обойти его невозможно без нарушения ToS.

## Получение доступа к Instagram (для каждого клиента)

Это самая сложная часть — сделай её один раз для клиента и токен будет
работать долго (60 дней, с автопродлением).

1. **Создай приложение на Meta for Developers**
   https://developers.facebook.com/apps → Create App → тип "Business"

2. **Добавь продукт Instagram Graph API** в приложение

3. **Свяжи Instagram-аккаунт клиента со страницей Facebook**
   (в настройках Instagram-аккаунта → Linked Accounts, или через
   Meta Business Suite)

4. **Получи Page Access Token** через Graph API Explorer
   https://developers.facebook.com/tools/explorer
   - выбери приложение
   - выбери страницу клиента
   - права: `instagram_basic`, `instagram_content_publish`, `pages_read_engagement`, `pages_show_list`
   - сгенерируй токен

5. **Обменяй краткосрочный токен на долгоживущий (60 дней)**:
   ```
   GET https://graph.facebook.com/v21.0/oauth/access_token
       ?grant_type=fb_exchange_token
       &client_id={app-id}
       &client_secret={app-secret}
       &fb_exchange_token={short-lived-token}
   ```

6. **Узнай Instagram Business Account ID**:
   ```
   GET https://graph.facebook.com/v21.0/{page-id}?fields=instagram_business_account&access_token={token}
   ```

7. В боте: `/connect` → вставь `ig_user_id` и `access_token`

> Для продакшена и множества клиентов имеет смысл сделать веб-страницу
> с OAuth-кнопкой "Войти через Facebook", чтобы не собирать токены вручную —
> это можно добавить отдельным модулем.

## Короткая инструкция для клиента

### 1. Подключить Instagram
Instagram должен быть **Business или Creator** и быть подключён к Facebook Page.

В боте:
`/connect`

Бот попросит:
- **Instagram Business Account ID**
- **Page Access Token**

После успешного подключения бот покажет:
`✅ Подключено: @username`

### 2. Первый пост — бесплатно
Введи:
`/newpost`

Дальше:
1. Пришли фото или видео.
2. Для карусели пришли несколько фото.
3. Напиши подпись или `/skip`.
4. Выбери:
   - **Опубликовать сейчас**
   - **Запланировать**
5. Если запланировал — укажи дату и время в формате `ДД.ММ.ГГГГ ЧЧ:ММ` по МСК.

**Первый пост бесплатный.**

### 3. Подписка
После первого поста доступ продолжается по подписке:

**250 ⭐ Telegram Stars / 30 дней**

Для оплаты:
`/subscribe`

Оплата проходит прямо внутри Telegram. После успешной оплаты бот автоматически включает доступ.

### 4. Проверить доступ
`/status`

### 5. Управление публикациями
`/myposts` — посмотреть запланированные посты.

`/cancel ID` — отменить запланированный пост.

### 6. Помощь
`/start` — инструкция и меню команд.

`/terms` — условия.

`/paysupport` — вопросы по оплате.

## Команды бота

- `/start` — инструкция и статус доступа
- `/connect` — подключить Instagram
- `/newpost` — создать пост
- `/subscribe` — оплатить 250 ⭐ / 30 дней
- `/status` — проверить подписку
- `/myposts` — список запланированных постов
- `/cancel <id>` — отменить пост
- `/disconnect` — отключить Instagram
- `/terms` — условия использования
- `/paysupport` — помощь по оплате

## Как продавать это клиентам (идея для бизнеса)

- Подписка "автопостинг + статистика" — 500–1500₽/мес за аккаунт
- Для тех, кто ведёт несколько аккаунтов (агентства) — тариф за пакет
- Опция "контент-план на неделю вперёд" — загрузил все посты разом,
  бот сам публикует по расписанию
- Через тот же Graph API можно добавить официальную статистику охватов
  и вовлечённости — как отдельный платный отчёт

## Технические заметки

- Telegram отдаёт временную публичную ссылку на файл
  (`api.telegram.org/file/bot<token>/<path>`) — её и передаём в Instagram API,
  отдельный хостинг для картинок не нужен.
- Долгоживущий токен living 60 дней — нужно продумать автопродление
  (Meta даёт эндпоинт для обмена ещё не истёкшего токена на новый).
- Для видео Instagram обрабатывает контейнер асинхронно — бот сам
  дожидается статуса `FINISHED` перед публикацией.
- База — SQLite для простоты; для нескольких сотен активных клиентов
  стоит перейти на PostgreSQL.


## Railway — отдельный бот

Этот проект рассчитан на отдельный Railway-сервис и отдельный Telegram-бот.
Он не должен использовать токен или базу данных существующих ботов.

Переменные Railway:
- `TELEGRAM_BOT_TOKEN` — токен нового бота из @BotFather
- `META_GRAPH_API_VERSION` — `v25.0`
- `DB_PATH` (опционально) — путь к файлу SQLite, по умолчанию `/data/bot.db`
- `RUN_SCHEDULER` (опционально) — `0`, чтобы отключить фоновый планировщик
  в этом процессе (полезно, если бот запущен в нескольких экземплярах)

Важно: база данных хранится в `/data/bot.db` — примонтируй постоянный Railway
volume на `/data`, иначе база потеряется при пересоздании контейнера. Если нужен
мультиклиентский продакшен, лучше вынести базу в PostgreSQL.
